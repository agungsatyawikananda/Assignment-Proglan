# Laporan Programming Assignment 1: Basic C++

Mengimplementasikan fungsi yearsOld:
- Menghitung selisih tahun lahir dengan tahun sekarang. Jika belum melewati, maka dikurangi 1.
  
Mengimplementasikan fungsi monthsOld:
- Menghitung total bulan sejak lahir. Dengan mengalikan selisih tahun dengan 12 kemudian ditambah selisih bulan. Jika belum melewati, dikurangi 1.

Mengimplementasikan fungsi dayOfDate:
- Menentukan hari dari tanggal lahir dengan fungsi mktime, kemudian menghitung tm_wday, lalu dikonversi ke nama hari

Contoh Input / Output
Input : 07/09/2007
Output : 18 222 Jumat
